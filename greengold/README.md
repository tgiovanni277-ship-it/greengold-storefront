# GreenGold

Tienda visual de ropa urbana para hombre y accesorios en oro laminado con esmeraldas. Este primer entregable es una experiencia de frontend hecha con Next.js; los productos, precios y carrito son de demostración.

## Ejecutar en local

Desde la carpeta `greengold`:

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000). La página de inicio está en `/`.

## Publicar en Vercel

Conecta el repositorio Git en Vercel y configura `greengold` como **Root Directory**. Vercel detecta Next.js y configura los comandos de instalación y compilación automáticamente.
